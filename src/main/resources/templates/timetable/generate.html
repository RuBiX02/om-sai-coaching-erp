Generate the classes of a date range

Every occurrence of the recurring timetable inside the range becomes an OPEN class session, which can then be marked for attendance. The run is safe to repeat: a class that already exists is never touched or duplicated, holidays and cancelled occurrences are skipped, and completed classes with their attendance stay exactly as they are.

A generated class is a normal class session: it appears in the session list, the teacher can mark its attendance and the attendance reports count it like any other class. Only OPEN classes are generated - a class that was already completed is never overwritten.
